
# КТ4 — Практикум по алгоритмам

Решения шести алгоритмических задач на Java.

## Список задач

1. **Task1** — сумма значений вершин бинарного дерева по уровням. BFS.
2. **Task2** — поиск k наиболее частых чисел. HashMap и сортировка.
3. **Task3** — медиана потока чисел. Две кучи.
4. **Task4** — максимальная сумма пути в бинарном дереве. DFS и динамическое программирование.
5. **Task5** — k-я наименьшая сумма пар из двух отсортированных массивов. Мини-куча.
6. **Task6** — медиана скользящего окна. Две кучи и отложенное удаление.

## Требования

- Java
- Ввод через стандартный ввод
- Вывод через стандартный вывод

## Компиляция и запуск

Из корня проекта:

```bash
javac src/Task1.java
java -cp src Task1
```

Для остальных задач замените `Task1` на `Task2`, `Task3` и так далее.

## Сложность

- Task1: O(n) по времени и O(n) по памяти.
- Task2: O(n + d log d), где d — число различных значений.
- Task3: O(n log n) по времени.
- Task4: O(n) по времени и O(n) по памяти.
- Task5: O(k log k) по времени, O(k) по памяти.
- Task6: O(n log n) по времени, O(n) по памяти.
